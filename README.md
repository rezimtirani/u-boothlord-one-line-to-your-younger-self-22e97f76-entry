One funny line of advice to your younger self, for the
[make.fun bounty "One Line to Your Younger Self"](https://make.fun/bounty/u-boothlord-one-line-to-your-younger-self-22e97f76).

## The entry

> Don't practice your autograph — one day you'll sign everything with a thumbprint and forget your own PIN.

105 characters — inside the 200-character gate, single line, no padding.

## How it works

`main.py` (Python standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, the file the house gate and judge read.
A `validate_line()` gate check refuses a blank, over-long, or multi-line
entry before anything is written.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
